# Eva's dotfiles

These are my dotfiles (forked from [liskin's dotfiles](https://github.com/liskin/dotfiles),
or perhaps more accurately **my personal monorepo**. I use this with
`core.worktree` set to my home directory, so no fancy dotfiles managers or
setup scripts, just plain git, and perhaps a few Makefiles here and there.

There's also the [root](https://github.com/EvaJanouskova/dotfiles/tree/root) branch,
which I use as a separate git worktree with `core.worktree = /`.
